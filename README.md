# Task Flow — Task Management App

A simple task management application built with React to practise frontend development, component-based UI, state management, and browser storage.

## About the Project

Task Flow is a personal learning project created to improve my React development skills. It provides a starting point for organising tasks in a simple web interface.

## Features

- Manage tasks through a React interface
- Use React state to handle application data
- Save tasks in browser local storage so they can persist after refreshing the page
- Responsive layout for different screen sizes

## Tech Stack

- **React** — building the user interface
- **JavaScript** — application logic
- **CSS** — styling
- **Vite** — development server and build tool
- **ESLint** — code quality checks
- **Git & GitHub** — version control

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/dewni-hettiarachchi/task-flow.git
   ```

2. Open the project folder:

   ```bash
   cd task-flow
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
